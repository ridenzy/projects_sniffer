# Branding and name use

## Purpose and license boundary

Project Sniffer is an MIT-licensed open-source project. The permissions in
[LICENSE](LICENSE) include commercial use, modification, and redistribution of
the licensed code and documentation, subject to the license terms. This guide
addresses how the project's identity is presented; it does not add conditions
to the MIT License or withdraw any rights already granted under it.

## Accurate references and attribution

You may accurately describe software as a "fork of Project Sniffer", "based on
Project Sniffer", or "compatible with Project Sniffer" when those statements
are true. You may link to the [upstream repository](https://github.com/ridenzy/projects_sniffer)
and retain technical package names where needed for compatibility.

Keep required MIT copyright and permission notices when redistributing
licensed material. Clearly identify any independent maintainer, changes,
service provider, and support arrangements when confusion is possible.

## Official project identity

Do not describe a third-party fork, altered build, analyzer pack, consulting
service, website, account, or release as an official Project Sniffer offering
unless it actually is. Independent offerings should use distinct public-facing
branding and must not suggest sponsorship, endorsement, or an official release
channel where none exists.

The upstream repository identifies the current public Project Sniffer source.
An independently published build does not become an official release merely
because it incorporates unmodified MIT-licensed code.

## Name, logo, and permissions

Use the project name truthfully in documentation, attribution, comparisons,
and descriptions of compatibility. Avoid presenting any Project Sniffer logo or
visual identity as the primary branding of an unrelated or unofficial service
in a way that could confuse users about who maintains it.

For a proposed official collaboration or co-branded offering, request a
suitable contact method through a non-sensitive repository issue if the issue
tracker is available.

For optional professional services, see [COMMERCIAL.md](COMMERCIAL.md).
